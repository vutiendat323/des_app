# DES Web Visualization

This project is a modern web application for visualizing the detailed steps of the DES (Data Encryption Standard) algorithm, supporting all major DES modes: ECB, CBC, CFB, and OFB. It is designed for educational, research, and demonstration purposes, allowing users to see every intermediate step of DES encryption and decryption, including key generation, block processing, Feistel rounds, and more.

## Features

- **Interactive Web Interface:** Modern, responsive UI with Bootstrap, sidebar navigation, and collapsible accordions for each block and round.
- **Multi-Mode Support:** Visualizes DES steps for ECB, CBC, CFB, and OFB modes, both for encryption and decryption.
- **Step-by-Step Breakdown:** Shows key generation, block splitting, subkey schedule, Feistel rounds, f-function, S-boxes, permutations, and XOR operations.
- **Log File Integration:** Reads detailed `.json` log files generated during DES operations and renders all intermediate states.
- **Copy & Download:** Easily copy ciphertext/plaintext or download the log file for further analysis.
- **Graceful Error Handling:** Handles missing or incomplete log data with clear fallback messages.
- **Mathematical Notation:** Uses subscript notation for variables (e.g., L₀, R₀, Cᵢ, Dᵢ, Subkeyᵢ) for clarity.

## How It Works

1. **Upload or select a DES log file** (in `.json` format) generated by the backend or another tool.
2. **View the results:** The app parses the log and displays all intermediate steps for each block and round, according to the selected DES mode.
3. **Explore details:** Expand/collapse blocks and rounds to see permutations, subkeys, S-box substitutions, XOR operations, and more.
4. **Copy or download:** Use the provided buttons to copy ciphertext/plaintext or download the log for offline study.

## Usage

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
2. **Run the app:**
   ```bash
   python run.py
   ```
3. **Access the web interface:**
   Open your browser and go to `http://localhost:5000` (or the configured port).

## Log File Format
- Log files are in JSON format and contain all intermediate states for each block and round.
- Supported fields: `key_generation`, `block_processing`, `xor_operation`, `keystream_generation`, `des_encryption`, `des_decryption`, etc.
- The structure adapts to the selected DES mode (see sample logs in `app/static/log/`).

## Customization
- **Templates:** UI is modular, with partials for each DES mode and round details. You can easily customize the look or add new features.
- **Styling:** CSS is based on Bootstrap and custom styles in `app/static/css/`.
